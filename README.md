# 🏁 こどもレーシング グランプリ

こども向けの **4人たいせん レースゲーム**（PC / スマホ・タブレット）。

- MacBook を「サーバ」にして、**おなじ Wi-Fi のスマホから IP を指定して参加**できます
- **ホスト（MacBook）も いっしょにレースに参加**できます
- 人が 4人そろわないときは **NPC（コンピュータ）が自動で参加**します
  （うでまえは 🔰へた / 🙂ふつう / 😎じょうず の3段階。**へたな子が多めに入る**ので勝ちやすい）
- ステージは **3コース**、グランプリで走ると **おかね（日本円）** がたまり、
  レースのあとの **ガレージ（ショップ）** でマシンやパーツを買って つぎのレースに反映されます
- **実在のスーパーカー／オープンカー風のマシン 8種**から選べます
  （ウェッジ型V12・ミッドシップ・GTクーペ・オープンカー・ハイパーカー・バギーなど。性能もちがいます）

インストールする npm パッケージは **ゼロ**です（Node.js の標準機能だけで動きます）。
ビルドしたファイルは **Google Cloud Storage にそのまま置ける静的サイト**です。

## 3. すぐ遊ぶ（MacBook + スマホ）

```bash
git clone <このリポジトリ>
cd race-game
npm install     # 依存ゼロなので一瞬で終わります（省略可）
npm start       # サーバ起動（ポート 8080）
```

ターミナルにこう出ます:

```
  🏁  こどもレーシング グランプリ  サーバ起動！
  ------------------------------------------------
  この MacBook で あそぶ  : http://localhost:8080/
  スマホ・タブレットから  : http://192.168.0.12:8080/
  ------------------------------------------------
```

1. **MacBook（ホスト）**: `http://localhost:8080/` を開く →
   なまえと色を入れて **「みんなで あそぶ」**
   （「サーバのアドレス」は空のままで OK。いま見ているサーバにつながります）
2. **こどものスマホ**: MacBook と **おなじ Wi-Fi** につないで、
   Safari / Chrome で **`http://192.168.0.12:8080/`**（表示された IP）を開く →
   なまえを入れて **「みんなで あそぶ」**
3. 全員そろったら、**ホストの画面の「🏁 レース スタート！」** を押す

- 参加できるのは **4人まで**。5人目からは「かんせん」になり、次のレースから参加できます
- 4人に足りないぶんは **NPC** が入ります。うでまえは自動で
  **🔰へた → 🙂ふつう → 🔰へた → 😎じょうず** の順に割りあて（＝へたな子が多め）。
  さらにホストが「やさしい / ふつう / つよい」で全体を上下できます
- ネットがなくても遊べます: タイトルで **「ひとりで あそぶ」**（NPC 3台と対戦・サーバ不要）

### ポートを変えたいとき

```bash
PORT=3000 npm start
```

### スマホの入力を楽にする

スマホの URL に `?server=192.168.0.12` を付けておくと、アドレス欄が最初から埋まります。

```
http://192.168.0.12:8080/?server=192.168.0.12
```

## 5. ゲームの中身（仕様）

### コース（3ステージ）

| コース | 路面 | むずかしさ | とくちょう |
|---|---|---|---|
| なかよしサーキット | しばふ | ★☆☆ | 道がひろく、カーブがゆるい |
| サンサンビーチ | すな | ★★☆ | S字とヘアピン |
| キラキラゆきやま | ゆき | ★★★ | すべる（グリップが低い）＋細かいカーブ |

### グランプリとおかね

- **グランプリ** = 3コースを順番に走る（1レースだけ / 周回数 1〜5 もホストが選べます）
- 順位ポイント: **1位 9pt / 2位 6pt / 3位 3pt / 4位 1pt**
- おかね（円）の入りかた

  | できごと | 金額 |
  |---|---|
  | コイン 1枚 | ¥50 |
  | アイテムボックス | ¥30 |
  | 1周ゴール | ¥200 |
  | ドリフト | ¥15 / 秒 |
  | 追い抜き | ¥100 |
  | ゴール順位 | ¥2,200 / ¥1,500 / ¥1,000 / ¥700 |

- 1レースで だいたい **¥3,000〜¥6,000**。おかねは **レース後のガレージ**で使います
- おかね・買ったものは **名前ごとに保存**されます
  （サーバ: `data/profiles.json` / ひとりであそぶ: ブラウザの localStorage）

### ガレージ（カスタマイズ）

- **マシン**（8種）: 買うと乗りかえられます。スピード・加速・グリップがちがいます

  | マシン | タイプ | ねだん | とくちょう |
  |---|---|---|---|
  | ハヤブサ GT-R | ツインターボ GTクーペ | ¥0 | バランス型（最初のマシン） |
  | ちびスポーツ | かるいオープン2シーター | ¥0 | 加速とカーブが得意 |
  | クラシック オープン | むかしのオープンカー | ¥1,500 | おそいけど **おかね1.15倍** |
  | ソラカゼ ロードスター | オープンカー | ¥3,000 | グリップ最高 |
  | モンスター バギー | オフロード | ¥4,000 | **道の外でもおそくならない** |
  | ロッソ・ヴェント | ミッドシップ スーパーカー | ¥9,000 | 加速・グリップが高い |
  | トロ・ヴェルデ | V12 ウェッジ スーパーカー | ¥13,000 | 直線が速い／すべりやすい |
  | ゼロワン ハイパー | ハイパーカー | ¥24,000 | 最速・**スピンしにくい** |

- **パーツ**（Lv.0〜3、買うほど強い）: エンジン / タイヤ / ブースター / アーマー / ターボスタート
- **1レースだけのアイテム**: ラッキーコイン（おかね1.25倍）/ アイテムポケット / ねんちゃくタイヤ
- **見た目**: ボディカラー・かぶりもの（👑🧢😈🌸）・しっぽ（🌈✨🔥🫧）

> パーツの効果は **マシンの性能にかけ算**されます（`shared/catalog.js` の `statsFor()`）。
> NPC のパーツは「人間プレイヤーの平均レベル」に自動で合わせるので、
> 強くなりすぎ／勝てなさすぎになりません（🔰へた はさらに 1レベル低い）。

### NPC の うでまえ（3段階）

| うでまえ | ベストラップ | どんな走り | 乗るマシン |
|---|---|---|---|
| 😎 じょうず | 約 15.5 秒 | ラインがきれい・ブレーキも正確・アイテムも上手 | スーパーカー系 |
| 🙂 ふつう | 約 18.6 秒（+20%） | ときどきふくらむ・アイテムをむだ使い | GTクーペ／ロードスター／バギー |
| 🔰 へた | 約 22.3 秒（+45%） | 曲がるのが遅れて大きくふくらむ・ブレーキを踏み忘れて草へ | クラシック／ちびスポーツ（おそい） |

- 入る順番は `shared/constants.js` の `NPC_MIX`（既定 `['rookie','normal','rookie','pro']`）。
  **人が1人なら「へた・ふつう・へた」**で、じょうずは4台目からしか出てきません
- ちがいは「スピード上限・カーブで出す速さ・ハンドルの反応の速さ・
  どれだけ先を見るか・しっぱいの確率・乗るマシン・パーツのレベル」で作っています
  （`NPC_TIERS`）
- 差がちゃんとついているかは `npm run simtest` が毎回チェックします

### ネットワークのしくみ

```
  スマホ ─┐                      ┌─ 30回/秒 ぜんぶの位置を配信（snap）
  スマホ ─┼─ WebSocket(/ws) ──▶ MacBook のサーバ
  MacBook ┘   そうさだけ送る        └─ レースの計算はサーバだけが行う（不正なし・ズレなし）
```

- サーバが 1/30 秒ごとにレースを計算し、全員に同じ状態を配信します（サーバ権威型）
- クライアントは受け取った 2つのスナップショットの間を **補間・少し先読み**して 60fps で描画
- とちゅうで通信が切れた人のクルマは **NPC が引きつぎ**ます（レースが止まりません）
- スマホでほかのアプリを見たり画面を消すと、ブラウザが止まってそうさが届かなくなります。
  そのときも **2秒で AI が代わりに運転**（クルマの横に 🤖 が出ます）。
  もどってボタンを押せば、すぐ自分の運転にもどります
- WebSocket は **依存パッケージなしの自作実装**（`server/ws.js`, RFC 6455）

## 6. 開発のしかた

### npm スクリプト

| コマンド | なにをする |
|---|---|
| `npm start` | サーバ起動（`http://localhost:8080/`） |
| `npm run dev` | ファイルを保存すると自動で再起動（`node --watch`） |
| `npm run build` | `dist/` を作る（Cloud Storage にアップする中身） |
| `npm run preview` | `dist/` の中身をサーバで配信して確認 |
| `npm run simtest` | 画面なしで 3コースを NPC だけで走らせ、完走できるか確認 |
| `npm run smoke` | サーバ＋2人プレイ＋ブラウザ起動までまとめて動作確認 |
| `npm run deploy` | ビルドして Cloud Storage にアップ（`BUCKET=...` が必要） |

### フォルダの構成

```
race-game/
├── shared/            サーバとブラウザで「共通」のゲームロジック（ここが本体）
│   ├── constants.js     速さ・おかね・アイテムなどの数値（バランス調整はここ）
│   ├── tracks.js        3コースの形（中心線＋道幅）とコイン配置
│   ├── cars.js          えらべるマシン8種の性能・名前
│   ├── catalog.js       ショップの中身と「最終的な性能の計算」
│   ├── race.js          レースのシミュレーション（物理・アイテム・順位）
│   └── room.js          ロビー→レース→けっか→ショップ の進行管理
├── server/            MacBook で動かすサーバ（Node 標準機能のみ）
│   ├── index.js         HTTP（ゲーム配信）＋ WebSocket ＋ メインループ
│   ├── ws.js            WebSocket の自作実装
│   └── profiles.js      おかね・パーツの保存（data/profiles.json）
├── client/            ブラウザ側
│   ├── index.html
│   ├── css/style.css
│   └── src/
│       ├── main.js      画面のきりかえ・通信・HUD
│       ├── net.js       WebSocket 接続 ／ ひとりであそぶ用のローカル接続
│       ├── render.js    コースとクルマの描画（Canvas 2D）
│       ├── cars.js      マシンごとの見た目（上から見たかたち）
│       ├── ui.js        タイトル・ロビー・ガレージ・けっか画面
│       ├── input.js     キーボード／タッチ／ゲームパッド
│       ├── sfx.js       効果音（WebAudio で合成。音声ファイル不要）
│       └── store.js     ブラウザ側の保存
├── tools/             ビルドとテスト
│   ├── build.js  simtest.js  smoke.js  wsclient.js  deploy.sh
└── dist/              npm run build で生成（Git 管理外）
```

### だいじな設計

- **同じコードがサーバとブラウザの両方で動きます。**
  `shared/room.js` はサーバでは WebSocket 越しに、
  「ひとりであそぶ」ではブラウザの中で直接動きます（`client/src/net.js` の `LocalLink`）。
  → オフラインとオンラインで**遊びの中身がズレません**。
- **ビルドツール（webpack / Vite）を使いません。**
  ブラウザがそのまま読める ES モジュールなので、`npm run build` は
  「ファイルを `dist/` にコピーして import のパスをそろえるだけ」です。
- **画像・音声ファイルを1つも使いません。** すべて Canvas と WebAudio で生成しています
  （＝ アップロードするファイルが軽い・壊れにくい）。

### よくある改造

| やりたいこと | 直す場所 |
|---|---|
| 速さ・おかね・アイテムのバランス | `shared/constants.js` |
| NPC を もっと弱く／強くする | `shared/constants.js` の `NPC_TIERS`（うでまえの中身）と `NPC_MIX`（入る順番） |
| コースを増やす | `shared/tracks.js` の `TRACK_DEFS` に `control`（コースの通過点）を追加し、`shared/constants.js` の `DEFAULT_GP` に ID を足す |
| マシンを増やす・性能を変える | `shared/cars.js`（見た目は `client/src/cars.js` の `MODELS` に同じ ID で追加） |
| ショップの品ぞろえ | `shared/catalog.js` |
| アイテムを追加 | `shared/constants.js` の `ITEMS` / `ITEM_TABLE` ＋ `shared/race.js` の `useItem()` |
| 参加人数を増やす | `shared/constants.js` の `RACERS`（`shared/tracks.js` の `makeStartGrid` のならびも増やす） |

コースを増やしたら、必ず走れるか確認してください:

```bash
npm run simtest   # 3コース（追加したコースも）を NPC が完走できるかチェック
```

## 7. Google Cloud Storage で公開する

### 7-1. ビルド

```bash
npm run build      # dist/ に index.html, css/, src/, shared/ ができる
npm run preview    # http://localhost:8080/ で dist/ の中身を確認
```

`dist/` の中身は**完全な静的サイト**（HTML + CSS + JS だけ、合計 150KB 程度）です。

### 7-2. はじめての1回だけ: バケットを作って公開設定

```bash
gcloud auth login
gcloud config set project <あなたのプロジェクトID>

# バケット作成（名前は世界で1つ。例: kids-race-yourname）
gcloud storage buckets create gs://kids-race-yourname \
  --location=asia-northeast1 \
  --uniform-bucket-level-access

# だれでも読めるようにする（公開サイトにするため）
gcloud storage buckets add-iam-policy-binding gs://kids-race-yourname \
  --member=allUsers --role=roles/storage.objectViewer

# 静的サイトの設定（トップページと 404 ページ）
gcloud storage buckets update gs://kids-race-yourname \
  --web-main-page-suffix=index.html --web-error-page=404.html
```

### 7-3. アップロード（毎回）

付属スクリプトを使う場合:

```bash
BUCKET=kids-race-yourname npm run deploy
#   はじめての1回で 7-2 もまとめてやりたいときは:
BUCKET=kids-race-yourname npm run deploy -- --setup
```

手でやる場合:

```bash
npm run build
gcloud storage rsync dist gs://kids-race-yourname \
  --recursive --delete-unmatched-destination-objects

# キャッシュ設定（HTML は毎回読み直す、JS/CSS は5分）
gcloud storage objects update "gs://kids-race-yourname/**.html" \
  --cache-control="no-cache, max-age=0"
gcloud storage objects update "gs://kids-race-yourname/**.js" \
  --cache-control="public, max-age=300"
gcloud storage objects update "gs://kids-race-yourname/**.css" \
  --cache-control="public, max-age=300"
```

開く URL:

```
https://storage.googleapis.com/kids-race-yourname/index.html
```

> **JS のパスについて**: このゲームは ES モジュール（`import`）を使うので、
> `index.html` / `src/` / `shared/` / `css/` の**フォルダ構成をくずさず**
> アップロードしてください（`gcloud storage rsync dist ...` ならそのままで OK）。

### 7-4. 独自ドメイン・HTTPS・CDN（やりたい場合）

`storage.googleapis.com` の URL でも HTTPS で遊べますが、
`https://race.example.com` のようにしたい場合は
**Cloud Load Balancing + Cloud CDN** をバケットの前に置きます。

```bash
gcloud compute backend-buckets create race-backend --gcs-bucket-name=kids-race-yourname --enable-cdn
# 以降、URL マップ → HTTPS プロキシ（マネージド証明書）→ 転送ルール を作成
```

（`www.example.com` を CNAME で `c.storage.googleapis.com` に向ける昔の方法は
HTTP のみなので、HTTPS にしたい場合はロードバランサ方式を使ってください）

## 8. 公開版とみんなで遊ぶときの関係（だいじ）

Cloud Storage は**静的ファイルを配るだけ**のサービスで、
WebSocket サーバ（＝レースの計算役）を動かすことはできません。そのため:

| あそびかた | どこを開く | 4人たいせん |
|---|---|---|
| **① おうちで 4人たいせん**（メイン） | MacBook で `npm start` → スマホで `http://（MacBookのIP):8080/` | ✅ できる |
| **② Cloud Storage の公開版** | `https://storage.googleapis.com/<bucket>/index.html` | ❌「ひとりであそぶ」専用 |

さらに、ブラウザの決まりで **https のページから http:// や ws:// のサーバには接続できません**
（mixed content）。なので **4人であそぶときは、必ず MacBook の `http://…:8080/` を開いてください**。
公開版のタイトル画面には、その注意がじどうで表示されます。

> **外出先からもみんなで遊びたい場合**は、サーバ（`server/`）を HTTPS で動かす必要があります。
> 例: Cloud Run にデプロイして `wss://` でつなぐ（`server/index.js` は
> `PORT` 環境変数を見るのでそのまま動きます。クライアントの「サーバのアドレス」に
> `wss://your-app.a.run.app/ws` と入れて接続します）。
> まずは家の中の LAN で遊ぶ想定なので、既定はこの構成にしていません。

## 9. 困ったとき

| 症状 | 対処 |
|---|---|
| スマホから開けない | MacBook とスマホが**同じ Wi-Fi** か確認。ゲスト用ネットワークは端末同士が通信できないことがあります |
| はじめての起動で「接続を許可しますか？」 | macOS のファイアウォールです。**許可**してください（システム設定 → ネットワーク → ファイアウォール） |
| IP アドレスがわからない | サーバ起動時にターミナルに出ます。または「システム設定 → Wi-Fi → 詳細 → TCP/IP」 |
| ポート 8080 が使われている | `PORT=3000 npm start` のように変える |
| 「サーバに つながりません」と出る | アドレスを `192.168.0.12:8080` の形（`http://` は省略可）で入れる／サーバが起動しているか確認 |
| 公開版で「みんなであそぶ」ができない | 仕様です（[8章](#8-公開版とみんなで遊ぶときの関係だいじ)）。MacBook の URL を開いてください |
| 音が出ない | 画面を1回タップ／クリックしてください（ブラウザの決まりで、操作するまで音を鳴らせません） |
| スマホでボタンが出ない | ロビーの「タッチそうさ」を **ON** にする |
| おかねをリセットしたい | サーバ: `data/profiles.json` を消す ／ ひとりであそぶ: ブラウザのサイトデータを消す |
| 動きがカクつく | 参加台数を減らす、スマホの省電力モードを切る、ブラウザのタブを閉じる |

## 10. マシン名と商標について

マシンは実在のスーパーカー・オープンカーの形を参考にしていますが、
**名前はオリジナル**にしています（インターネットに公開する場合、
実在メーカー名・車名は商標なので、そのまま使うと問題になることがあるためです）。

おうちの中だけで遊ぶなら、`shared/cars.js` の `name` を
好きな実車名に書きかえるだけで、ゲーム内の表示すべてに反映されます。

```js
// shared/cars.js
{ id: 'wedge', name: 'トロ・ヴェルデ', /* ← ここを書きかえるだけ */ ... }
```
